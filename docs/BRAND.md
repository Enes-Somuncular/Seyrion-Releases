# Seyrion

**Sisteminin ritmini gör.** / **See your system's rhythm.**

Adın çıkış noktası “seyir”: sistemi gözlemlemek, zaman içindeki değişimi izlemek. GPU veya oyun özelliğiyle sınırlı olmayan, günlük performans hafızasına uygun bir ürün adı.

| Kullanım | Değer |
| --- | --- |
| Ürün adı | Seyrion |
| Sözcük işareti | seyrion |
| Koyu lacivert | `#0D1624` |
| Panel | `#182335` |
| Mint / canlı sinyal | `#67E1C1` |
| Mavi / ikincil sinyal | `#7BA2FF` |
| Metin | `#E5EDF7` |
| İkincil metin | `#91A6C0` |

Simge, iki farklı yük seviyesini birleştiren açık uçlu bir sinyal çizgisidir. Mavi nokta gözlemi temsil eder. Sistem tepsisinde de okunabilecek kadar yalın tutulur. Tipografi: Windows'ta Segoe UI; belge görsellerinde Segoe UI/Arial.

Dil: sakin, kısa ve ölçüme dayalı. “Kesin FPS artışı”, “tek tıkla hızlandırma” veya tahmini veriyi kesin ölçüm gibi sunan ifadeler kullanılmaz. Mevcut özelliklerle yol haritası ayrı gösterilir.

Hero görseli marka illüstrasyonudur; gerçek ölçüm veya uygulama ekran görüntüsü değildir. Logo ve ürün kimliğinin hakları saklıdır.
